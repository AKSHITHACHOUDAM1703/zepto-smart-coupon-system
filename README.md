# 🛒 Zepto Smart Coupon System

## 🚀 Overview

This project predicts whether a user should receive a coupon based on their shopping behavior.

## 🎯 Features

* Predicts coupon usage using Machine Learning
* Interactive web app using Streamlit
* Simple and user-friendly interface

## 🧠 Tech Stack

* Python
* Scikit-learn
* Pandas
* Streamlit

## ▶️ How to Run

```bash
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```

## 📊 Dataset

The dataset contains user purchase behavior such as:

* Last purchase days
* Average order value
* Cart value
* User type

## 📌 Use Case

Inspired by Zepto to optimize coupon distribution and improve sales.
